# دليل تجهيز وتشغيل CP4 ARENA على استضافة خارجية

## المتطلبات الأساسية
- **Node.js `>= 22.5.0`** (لأن المحرك الداخلي يستخدم `node:sqlite` المدمج في Node 22).
- **لحفظ البطولات واللاعبين وحسابات المساعدين والصور بعد سكون الموقع على Render (الباقة المجانية):**
  - أضف متغير البيئة `DATABASE_URL` برابط قاعدة بيانات **PostgreSQL** مجانية (مثل **Neon.tech** أو **Supabase** أو **Render Postgres**).
  - يقوم الخادم بمزامنة البطولات، اللاعبين، النتائج، التذكيرات، حساب المشرف الرئيسي، **جميع حسابات المساعدين** (مع رموز PIN والصلاحيات)، **وحتى الصور المرفوعة** تلقائياً مع PostgreSQL عند كل تعديل، ويسترجعها فور استيقاظ الموقع دون أي فقدان.

---

## 1. النشر على Render (الباقة المجانية Free بدون ضياع البيانات وحسابات المساعدين بعد السكون)
على باقة **Render Free**، يدخل الخادم في وضع السكون (Sleep) بعد 15 دقيقة من عدم النشاط ويُعاد إنشاؤه بقرص مؤقت فارغ؛ لذا اتبع الخطوات التالية:

1. أنشئ قاعدة بيانات **PostgreSQL مجانية** (مثلاً على [Neon.tech](https://neon.tech) أو من لوحة Render نفسها عبر **New + -> PostgreSQL**) وانسخ رابط الاتصال (`postgres://...` أو `postgresql://...`).
2. في إعدادات خدمة الويب على Render (**Environment -> Environment Variables**)، أضف:
   - `DATABASE_URL` = رابط PostgreSQL الذي نسخته (يحفظ كل البطولات واللاعبين وحسابات المساعدين والصور بعد السكون).
   - `JWT_SECRET` = نص عشوائي طويل (يبقي المشرف الرئيسي والمساعدين مسجلين للدخول تلقائياً بعد السكون).
   - `CP4_HEAD_ADMIN_USERNAME` = `Djilali` (اختياري).
   - `CP4_HEAD_ADMIN_PIN` = رمز PIN من 6 أرقام (اختياري).
   - `CP4_SUB_ADMINS_JSON` = (اختياري) مصفوفة JSON لحسابات المساعدين كنسخة بيئية إضافية إذا أردت تثبيتها في المتغيرات البيئية أيضاً:
     ```json
     [{"username":"sub1","displayName":"مساعد النتائج","pin":"123456","canEditScores":true,"canManagePlayers":true}]
     ```
3. إعدادات البناء والتشغيل في Render (**Web Service** وليس Static Site):
   - **Root Directory:** `cp4-arena-web` (إذا كان داخل مجلد فرعي في المستودع)
   - **Build Command:** `npm ci --include=dev && npm run build`
   - **Start Command:** `npm start`
4. بعد إعادة النشر، ستظهر للمشرف الرئيسي في لوحة الإدارة شارة خضراء: **«حفظ سحابي دائم (PostgreSQL)»**.
   - كما يقوم المتصفح تلقائياً بحفظ مرآة احتياطية على جهاز المشرف الرئيسي تتيح استعادة البيانات وحسابات المساعدين بضغطة زر في حال نسيان ضبط `DATABASE_URL`.

## 2. التشغيل المحلي أو على VPS (Ubuntu / Debian)
```bash
cd cp4-arena-web
cp .env.example .env
# عدّل .env وأضف JWT_SECRET (و DATABASE_URL إذا أردت مزامنة سحابية)

npm ci
npm run build
npm start
```
